# SmritiSetu NER

AI-based cognitive gaming and memory assistance platform for elderly dementia and memory-support users in the North Eastern Region of India.

This repository contains a polished SIH-ready React prototype with:

- Elderly-friendly dashboard with large controls, high contrast and text scaling.
- Adaptive cognitive game shell for memory, attention and orientation tasks.
- Voice-style memory assistant grounded in caregiver-approved family data.
- Family memory journal and routine/reminder flows.
- Caregiver dashboard with baseline analytics and explainable insights.
- Admin portal with regional content catalog, impact dashboard and audit logs.

Run locally:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

Important safety note: SmritiSetu is a support and engagement platform. It is not a clinical diagnostic tool and does not replace doctors, caregivers or emergency services.
